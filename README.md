# ニュース読み上げ

犯罪・事件系の記事を除いた最新ニュースを、スマホのブラウザで読み上げてくれるシンプルなWebアプリ(PWA)です。

## 使い方(2通り)

### A. サーバーを起動せず、ブラウザだけで使う

`public/index.html` を直接開く(ダブルクリック)か、`public/` フォルダを GitHub Pages などの静的ホスティングに置くだけで動きます。Node.jsのサーバーを起動する必要はありません。

この場合、ブラウザから公開のCORSプロキシ(`api.allorigins.win` など)経由で直接RSSを取得します。サーバー経由に比べると、プロキシがダウンしていたり遅い場合に取得に失敗することがあります。

### B. 自前サーバーを起動して使う(より安定)

```bash
npm install
npm start
```

起動後、スマホのブラウザから `http://<サーバーのIPアドレス>:3000` にアクセスしてください(スマホと同じWi-Fiに接続したPC等でサーバーを起動する場合)。この場合、RSS取得はサーバー側で行われるため、第三者のCORSプロキシを経由しません。

フロントエンドは起動時にまず自前サーバーの `/api/news` を試し、応答がなければ(=Aの静的ホスティングの場合)自動的にブラウザ単体のフォールバックに切り替わります。どちらの方法で開いても同じ `public/index.html` を使えます。

どちらの方法でも、ホーム画面に追加するとアプリのように起動できます(PWA)。

## 仕組み

- **ニュース取得・フィルタ**: NHKニュース・Yahoo!ニュース・Googleニュースの3つのRSSフィードを取得し、重複を除去した上で `public/newsFilter.js` のキーワードフィルタにより犯罪・事件・事故関連の記事を除外します。このロジックはサーバー (`server.js`, Node.jsの`require`) とブラウザ (`<script>`) の両方から同じファイルを読み込んで使う共通モジュールになっています。取得結果は5分間キャッシュします(サーバー側はメモリ、ブラウザ単体の場合は `localStorage`)。
- **フロントエンド** (`public/`): スマホ向けのシンプルなUI。記事一覧の表示、個別記事の読み上げ、全記事の連続読み上げ(次の記事へ自動で進む)、読み上げ速度・声の高さ・読み上げ音声の調整ができます。起動時にサーバーの `/api/tts` が使えるか自動判定し、使えれば Google Cloud Text-to-Speech の高品質な音声で、使えなければブラウザ標準の Web Speech API (`SpeechSynthesisUtterance`、追加費用不要)で読み上げます。
- **PWA対応**: `manifest.json` と `service-worker.js` により、スマホのホーム画面に追加してアプリのように起動できます(ニュース本体は常に最新を取得し、アプリの見た目部分だけをキャッシュします)。
- **再生中の画面消灯を防止**: スマホは無操作だとすぐ画面が消灯し、その拍子に読み上げが止まってしまうことがあるため、再生中はWake Lock API(対応ブラウザのみ)で画面消灯を防ぎます。読み上げの取得・再生に失敗した場合も、キャンセルによる失敗でなければ自動で2回まで再試行します。

## より自然な読み上げにするには

### 方法1: Google Cloud Text-to-Speech を使う(おすすめ・要サーバー起動)

サーバーモード(上記B)で `GOOGLE_TTS_API_KEY` を設定すると、Web Speech APIの代わりに Google Cloud の高品質な音声で読み上げるようになります。ブラウザ単体モード(A)では、APIキーを安全に扱えないため使えません。

使えるボイスの一覧はハードコードせず、サーバーが起動時にGoogle Cloud側へ毎回問い合わせて取得します。そのため **Chirp3-HD**(最新の生成AIベースの音声。従来のNeural2/Wavenetよりさらに自然で、月100万文字までの無料枠あり)が使える環境では自動的に選択肢に表示され、品質の高い順(Chirp3-HD > Studio > Neural2 > Wavenet > Standard)に並びます。画面上部の「読み上げ音声」から選んでください。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. 「APIとサービス」→「ライブラリ」で **Cloud Text-to-Speech API** を有効化(初回は課金アカウントの登録が必要ですが、無料枠(標準音声は月400万文字、Neural2/Wavenetは月100万文字程度)内であれば課金されません)
3. 「認証情報」→「認証情報を作成」→「APIキー」でキーを発行
4. プロジェクト直下に `.env` ファイルを作成し、以下のように書く(`.env.example` をコピーして編集してもOK)
   ```
   GOOGLE_TTS_API_KEY=発行したAPIキー
   ```
5. `npm start` でサーバーを起動すると、自動的にGoogle Cloudの音声が使われます(画面上部の「読み上げ音声」で声質を選べます)

`.env` は `.gitignore` 対象なので、GitHubには公開されません。APIキーは他人と共有したりリポジトリにコミットしたりしないよう注意してください。

### 方法2: 端末組み込みの音声を調整する(APIキー不要)

Google Cloud TTSを使わない場合、Web Speech APIの声質は端末の音声合成エンジンにほぼ依存します。

- 画面上部の「読み上げ音声」で、端末にある日本語の声を選び直せる(「試聴」ボタンで確認可能)。
- **Android**: 設定 → システム → 言語と入力 → テキスト読み上げの出力 で、優先エンジンを「Google」にし、日本語の音声データをダウンロードしておくと自然な声が使えます。
- **iPhone**: 設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語 で、各声の「音声の品質」を「拡張」または「プレミアム」にしてダウンロードしておくと、Safari上でも(声のリストが増えるわけではなく、同じ名前のまま)音質が上がります。ただしSafariのWeb Speech APIはこの音質向上が反映されない場合があり、その場合はブラウザ側の制限のため方法1(Google Cloud TTS)を使ってください。

## 犯罪・事件記事の除外について

`public/newsFilter.js` の `CRIME_KEYWORDS` に含まれる単語(「事件」「逮捕」「殺人」「事故」など)が記事タイトル・概要に含まれる場合、その記事は一覧から除外されます。キーワードは配列を編集するだけで自由に追加・削除できます。

## 動作確認について

このセッションのサンドボックス環境ではネットワークポリシーにより NHK/Yahoo!/Google のRSSや公開CORSプロキシへの直接アクセスがブロックされていたため、実際のニュース取得結果は確認できていません。以下は確認済みです。

- サーバーモード: RSS取得に失敗しても落ちずに空の一覧を返す
- ブラウザ単体モード: Playwrightで実ブラウザから静的サーバー(`/api/news`なし)にアクセスし、自前APIへのフォールバック判定・CORSプロキシ経由の取得処理・エラー時の表示がJSエラーなく動作することを確認

通常のインターネット環境で開けば、そのままニュースが取得・表示されるはずです。
