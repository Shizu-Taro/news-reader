# ニュース読み上げ

犯罪・事件系の記事を除いた最新ニュースを、スマホのブラウザで読み上げてくれるシンプルなWebアプリ(PWA)です。

## 使い方(2通り)

### A. サーバーを起動せず、ブラウザだけで使う

`public/index.html` を直接開く(ダブルクリック)か、`public/` フォルダを GitHub Pages などの静的ホスティングに置くだけで動きます。Node.jsのサーバーを起動する必要はありません。

この場合、ブラウザから公開のCORSプロキシ(`api.allorigins.win` など)経由で直接RSSを取得します。サーバー経由に比べると、プロキシがダウンしていたり遅い場合に取得に失敗することがあります。

### B. 自前サーバーを起動して使う(より安定)

```bash
npm install
npm start
```

起動後、スマホのブラウザから `http://<サーバーのIPアドレス>:3000` にアクセスしてください(スマホと同じWi-Fiに接続したPC等でサーバーを起動する場合)。この場合、RSS取得はサーバー側で行われるため、第三者のCORSプロキシを経由しません。

フロントエンドは起動時にまず自前サーバーの `/api/news` を試し、応答がなければ(=Aの静的ホスティングの場合)自動的にブラウザ単体のフォールバックに切り替わります。どちらの方法で開いても同じ `public/index.html` を使えます。

どちらの方法でも、ホーム画面に追加するとアプリのように起動できます(PWA)。

## 仕組み

- **ニュース取得・フィルタ**: NHKニュース・Yahoo!ニュース・Googleニュースの3つのRSSフィードを取得し、重複を除去した上で `public/newsFilter.js` のキーワードフィルタにより犯罪・事件・事故関連の記事を除外します。このロジックはサーバー (`server.js`, Node.jsの`require`) とブラウザ (`<script>`) の両方から同じファイルを読み込んで使う共通モジュールになっています。取得結果は5分間キャッシュします(サーバー側はメモリ、ブラウザ単体の場合は `localStorage`)。
- **フロントエンド** (`public/`): スマホ向けのシンプルなUI。記事一覧の表示、個別記事の読み上げ、全記事の連続読み上げ(次の記事へ自動で進む)、読み上げ速度・声の高さ・読み上げ音声の調整ができます。読み上げにはブラウザ標準の Web Speech API (`SpeechSynthesisUtterance`) を使うため、追加のAPIキーや費用は不要です。
- **PWA対応**: `manifest.json` と `service-worker.js` により、スマホのホーム画面に追加してアプリのように起動できます(ニュース本体は常に最新を取得し、アプリの見た目部分だけをキャッシュします)。

## より自然な読み上げにするには

Web Speech APIの声質は端末に入っている音声合成エンジンにほぼ依存するため、アプリ側でできる調整には限界があります。以下を試してください。

- 画面上部の「読み上げ音声」で、端末にある日本語の声を選び直せる(「試聴」ボタンで確認可能)。名前に Google / Enhanced / Premium / Neural などを含む声は比較的自然な傾向があり、自動的に優先候補として並べています。
- **Android**: 設定 → システム → 言語と入力 → テキスト読み上げの出力 で、優先エンジンを「Google」にし、日本語の音声データを「ネットワーク接続が必要」なものも含めてダウンロードしておくと、明らかに自然な声が使えるようになります。
- **iPhone**: 設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語 で、「Siri」などの高品質な声(ダウンロードが必要な場合あり)を選んでおくと、Safari上でもその声が使われます。

## 犯罪・事件記事の除外について

`public/newsFilter.js` の `CRIME_KEYWORDS` に含まれる単語(「事件」「逮捕」「殺人」「事故」など)が記事タイトル・概要に含まれる場合、その記事は一覧から除外されます。キーワードは配列を編集するだけで自由に追加・削除できます。

## 動作確認について

このセッションのサンドボックス環境ではネットワークポリシーにより NHK/Yahoo!/Google のRSSや公開CORSプロキシへの直接アクセスがブロックされていたため、実際のニュース取得結果は確認できていません。以下は確認済みです。

- サーバーモード: RSS取得に失敗しても落ちずに空の一覧を返す
- ブラウザ単体モード: Playwrightで実ブラウザから静的サーバー(`/api/news`なし)にアクセスし、自前APIへのフォールバック判定・CORSプロキシ経由の取得処理・エラー時の表示がJSエラーなく動作することを確認

通常のインターネット環境で開けば、そのままニュースが取得・表示されるはずです。
