# ニュース読み上げ

犯罪・事件系の記事を除いた最新ニュースを、スマホのブラウザで読み上げてくれるシンプルなWebアプリ(PWA)です。

## 仕組み

- **バックエンド** (`server.js`): NHKニュース・Yahoo!ニュース・Googleニュースの3つのRSSフィードをサーバー側で取得し、重複を除去した上でキーワードフィルタ (`lib/newsFilter.js`) により犯罪・事件・事故関連の記事を除外して `/api/news` で配信します。取得結果は5分間キャッシュします。
- **フロントエンド** (`public/`): スマホ向けのシンプルなUI。記事一覧の表示、個別記事の読み上げ、全記事の連続読み上げ(次の記事へ自動で進む)、読み上げ速度の調整ができます。読み上げにはブラウザ標準の Web Speech API (`SpeechSynthesisUtterance`) を使うため、追加のAPIキーや費用は不要です。
- **PWA対応**: `manifest.json` と `service-worker.js` により、スマホのホーム画面に追加してアプリのように起動できます(ニュース本体は常に最新を取得し、アプリの見た目部分だけをキャッシュします)。

## セットアップ

```bash
npm install
npm start
```

起動後、スマホのブラウザから `http://<サーバーのIPアドレス>:3000` にアクセスしてください(スマホと同じWi-Fiに接続したPC等でサーバーを起動する場合)。ホーム画面に追加するとアプリのように使えます。

## 犯罪・事件記事の除外について

`lib/newsFilter.js` の `CRIME_KEYWORDS` に含まれる単語(「事件」「逮捕」「殺人」「事故」など)が記事タイトル・概要に含まれる場合、その記事は一覧から除外されます。キーワードは配列を編集するだけで自由に追加・削除できます。

## 動作確認について

このセッションのサンドボックス環境ではネットワークポリシーにより NHK/Yahoo!/Google のRSSへの直接アクセスがブロックされていたため(403)、実際のニュース取得は確認できていません。サーバー自体はRSS取得に失敗しても落ちずに空の一覧を返すことは確認済みです。通常のインターネット環境で実行すれば、そのままニュースが取得・表示されます。
